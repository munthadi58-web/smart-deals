# Smart Deals — Starter v0.2

**Find More. Pay Less.**

منصة لاكتشاف العروض وأكواد الخصم، تبدأ بالسعودية ومهيأة للتوسع الدولي، بواجهة عربية أولاً.

## حالة المشروع
- تم إنشاء مشروع Supabase مستقل باسم `smart-deals`.
- تم تطبيق مخطط قاعدة البيانات الأولي والتحقق من الجداول السبعة.
- الصفحة الرئيسية تقرأ العروض المنشورة والسارية من Supabase عند ضبط متغيرات البيئة.
- عند عدم ضبط متغيرات البيئة، تعرض الصفحة بطاقات تجريبية موضحة بوضوح.
- لا توجد عروض حقيقية مضافة حالياً.

## تنبيه مهم حول البيانات
البطاقات الظاهرة قبل إعداد اتصال Supabase **بيانات تجريبية خيالية للتصميم فقط** وليست عروضاً حقيقية أو أسعاراً حالية. لا تُنشر عروض فعلية إلا بمصدر قابل للتحقق وسعر صحيح ومدة صلاحية واضحة.

## المتطلبات والتشغيل
- Node.js 20.9 أو أحدث
- npm

```bash
npm install
cp .env.example .env.local
npm run dev
```

افتح http://localhost:3000.

## إعداد اتصال Supabase
أضف القيم التالية إلى `.env.local` محلياً، أو إلى إعدادات Environment Variables في منصة الاستضافة:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

- Project URL و Publishable key متاحان من إعدادات مشروع Supabase.
- استخدم مفتاح `sb_publishable_` المخصص للواجهة.
- لا تضع service-role أو secret key في المتصفح أو في GitHub.
- مخطط قاعدة البيانات مطبق بالفعل في المشروع؛ لا تحتاج إلى تشغيل `supabase/schema.sql` مرة أخرى على قاعدة البيانات الحالية.

سياسات RLS الحالية تسمح بالقراءة العامة للبيانات النشطة والعروض والكوبونات المنشورة والسارية فقط. لا توجد سياسات كتابة عامة. يلزم بناء تسجيل دخول وصلاحيات إدارية آمنة قبل تفعيل الإضافة والتعديل.
