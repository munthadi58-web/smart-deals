# Smart Deals — Starter v0.1

**Find More. Pay Less.**

منصة لاكتشاف العروض وأكواد الخصم، تبدأ بالسعودية ومهيأة للتوسع الدولي، بواجهة عربية أولاً.

## تنبيه مهم حول البيانات
البطاقات الموجودة في الصفحة الرئيسية **بيانات تجريبية خيالية للتصميم فقط** وليست عروضاً حقيقية أو أسعاراً حالية. لا تُنشر عروض فعلية إلا بمصدر قابل للتحقق وسعر صحيح ومدة صلاحية واضحة.

## المتطلبات والتشغيل
- Node.js 20.9 أو أحدث
- npm

```bash
npm install
cp .env.example .env.local
npm run dev
```

افتح http://localhost:3000.

## إعداد Supabase
1. أنشئ مشروع Supabase واختر المنطقة بعد مقارنة التوفر وزمن الاستجابة.
2. افتح SQL Editor وشغّل الملف `supabase/schema.sql`.
3. أضف Project URL و anon/publishable key إلى `.env.local`.
4. لا تضع service-role key في المتصفح أو في GitHub.

سياسات RLS الحالية تسمح بالقراءة العامة للعروض والكوبونات المنشورة والسارية فقط. يلزم بناء تسجيل دخول وصلاحيات إدارية قبل تفعيل عمليات الإضافة والتعديل.
